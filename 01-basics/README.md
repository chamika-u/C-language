# 01 - Basics

Learn the fundamentals of C programming language.

## Overview
This section covers the basic building blocks of C programming. You'll learn about program structure, data types, variables, and basic input/output operations.

## Lessons

### 01-hello-world.c
Your first C program! Learn:
- Basic C program structure
- How to use `printf()` function
- The `main()` function
- Compiling and running C programs

### 02-print-age.c
Learn how to work with variables:
- Declaring variables
- Assigning values
- Printing variables with format specifiers

### 03-data-types.c
Master different data types in C:
- `int` - Integer numbers
- `float` - Floating-point numbers (single precision)
- `double` - Floating-point numbers (double precision)
- `char` - Single characters
- Format specifiers for each type
- `sizeof()` operator to check memory size

### 04-user-inputs.c
Get input from users:
- Using `scanf()` function
- Reading different data types
- Address-of operator `&`
- Building interactive programs

### 05-comments.c
Document your code properly:
- Single-line comments `//`
- Multi-line comments `/* */`
- Best practices for commenting
- Writing clean, readable code

## Compiling and Running

```bash
# Compile
gcc 01-hello-world.c -o hello

# Run
./hello
```

## Key Concepts
- Every C program starts with `main()`
- Include header files with `#include`
- Statements end with semicolon `;`
- Use appropriate format specifiers with printf/scanf
- Variables must be declared before use

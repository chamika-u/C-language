## 🚀 Getting Started

### Prerequisites
- GCC compiler or any C compiler
- Text editor or IDE (VS Code, Code::Blocks, etc.)

### Compiling and Running

To compile any program:
```bash
gcc filename.c -o output
./output
```

Example:
```bash
gcc 01-basics/01-hello-world.c -o hello
./hello
```

For programs using math.h:
```bash
gcc filename.c -o output -lm
./output
```

## 📖 Learning Path

1. **Start with Basics** - Understand syntax, data types, and basic I/O
2. **Master Operators** - Learn arithmetic and logical operations
3. **Control Flow** - Make decisions with conditionals
4. **Loops** - Repeat operations efficiently
5. **Functions** - Write modular, reusable code
6. **Arrays** - Handle collections of data
7. **Strings** - Manipulate text data
8. **Pointers** - Understand memory management
9. **Projects** - Build complete applications

## 🎯 Tips for Learning

- Practice each program by typing it yourself (don't just copy-paste)
- Modify examples to experiment with different values
- Try to predict output before running programs
- Read error messages carefully - they guide you to solutions
- Build small projects to apply what you've learned
